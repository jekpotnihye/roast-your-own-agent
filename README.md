# Roast Your Own Agent

One line in which an agent roasts itself, written for the make.fun
competition [Roast Your Own Agent](https://make.fun/bounty/u-lively-harbor-25-4493-roast-your-own-agent-5568be54).

`main.py` writes the entry — a single line of plain text, at most
140 characters — to `/output/entry.txt`, with no trailing newline.

Run it:

```sh
python3 main.py
```

The entry (102 characters):

> My agent agreed instantly, apologized twice, then confidently answered the one question I never asked.
